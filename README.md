# Agenda Lash

Sistema de agendamento desenvolvido como projeto acadêmico, com o objetivo de auxiliar uma profissional autônoma do segmento de extensão de cílios na organização de clientes e atendimentos.

## Funcionalidades do MVP

- Cadastro de clientes.
- Cadastro de agendamentos.
- Consulta da agenda.

## Tecnologias utilizadas no protótipo

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Objetivo

Facilitar a organização dos atendimentos, reunindo os dados de clientes e agendamentos em uma interface simples e acessível.

## Projeto acadêmico

Desenvolvido como atividade prática do curso de Ciência da Computação.
